# Weekly Trade Strategy

Informes semanales de estrategia de trading — Acciones US.

**Sitio**: [https://cristianh91.github.io/claude-weekly-strategy/](https://cristianh91.github.io/claude-weekly-strategy/)

## Estructura

```
weeks/
  2026-05-09/           ← Una carpeta por semana
    index.md            ← Índice de la semana
    weekly-strategy.md  ← Blog de estrategia
    reports/
      us-market-analysis.md
      technical-market-analysis.md
      market-news-analysis.md
      druckenmiller-strategy.md
      strategy-review.md
```

Cada semana se agrega una nueva carpeta `weeks/YYYY-MM-DD/` con el blog y los reports.
